安装是怎么做的

静默安装不是靠 root 硬跑 pm，而是把应用自身挂进 app_process， 让它在 system 身份下走 PackageInstaller 会话 API——这才是没有确认框的真静默。

  1. 1
    安装代理

    把自身 APK 通过 CLASSPATH 交给 app_process，在 system 身份下提交安装会话，全程无弹窗。这条通道要求命令以 root 或 adb shell 身份执行，所以必须先完成无线调试配对——用应用自己的 uid 跑会被 SELinux 拦掉。

  2. 2
    本地 pm install

    代理不可用时退回到 pm install -r -d 覆盖安装。

  3. 3
    无线调试推包

    再退一步，把包推到 /data/local/tmp 后执行 pm install。

  4. 4
    设备所有者会话

    owner 权限下的 PackageInstaller 静默会话，作为不依赖 shell 的兜底。

  5. 5
    系统安装器

    全部失败时拉起系统安装界面，把选择权交回给你。

使用

三步开始

整个流程不需要数据线，不需要电脑。首次使用唯一要做的， 是在系统设置里打开无线调试。

01

打开无线调试

设置 → 开发者选项 → 无线调试。系统要求 Android 11 及以上。

设置 › 开发者选项 › 无线调试
02

在 PaperLite 里配对

进「配对」页搜索服务端口，手动输入配对码，或用识别按钮自动读取。配对是安装代理能跑起来的前提。

配对页 › 搜索端口 › 输入配对码
03

开始操作

通道自动就绪。装包、卸应用、跑命令，直接在对应页面里做。

安装页 › 选包 › 开始安装
为什么无线调试要 Android 11 以上

mDNS 服务发现是 Android 11 才引入的机制，低版本只能手工填端口。

数据不出设备

没有账号、没有统计、没有上传。服务器地址只是你自己填的一个可选开关。

遇到问题

设置页有「上次异常退出」，里面是完整崩溃堆栈，复制出来就能定位。

公告

欢迎使用 PaperLite

info

先在「配对」页完成无线调试配对，配对成功后「安装」「终端」等页面即可使用。配对码可以手动输入，也可以用「识别配对码」按钮自动读取。

静默安装是怎么做到的

info

PaperLite 会把自身 APK 挂给 app_process，让它在 system 身份下走 PackageInstaller 会话 API 提交安装，所以不会出现确认弹窗。如果这条通道失败，会依次回退到 pm install、无线调试推包、设备所有者会话，最后才是系统安装界面。

装不上时怎么排查

warn

安装页有一块「安装诊断」，会真的跑一遍安装代理命令并把系统返回的原始输出贴出来。ClassNotFoundException 说明入口没被找到，Permission denied 说明 SELinux 拦了。

公告与服务器无关

info

本页面显示的公告保存在手机本地，服务器关着也能看到。如果你填了远程公告地址，能连上就会更新，连不上则继续显示本地这份。

应用内不连接任何固定服务器，也不上报任何统计。 公告地址是可选的，留空就完全离线使用。

常见问题

  • 为什么第一次用要配对？

    没有 root 也没有设备所有者时，高权限操作只能通过 adb 通道执行，而 adb 通道靠无线调试建立。

  • 装得上但没静默？

    说明代理通道没成功，日志里会写明走了哪条通道、失败原因。可以到终端页手动执行安装命令。

  • 系统应用卸不掉？

    系统应用会被系统拒绝卸载，PaperLite 会自动降级为冻结停用，效果接近。
